# HWHHideButtonsExt

[![Version](https://img.shields.io/badge/version-2.33-blue.svg)](https://github.com/Green-oGo/HWHHideButtonsExt/raw/refs/heads/main/HWHHideButtonsExt.user.js)

**HWHHideButtonsExt** — это расширение для популярного скрипта [HeroWarsHelper](https://github.com/), предназначенное для добавления новых удобных функций и автоматизации рутинных задач в игре Hero Wars.

> ⚠️ **Внимание:** Данный скрипт является **расширением** и требует обязательной установки и работы базового скрипта **HeroWarsHelper**.

## ✨ Возможности

Скрипт добавляет новые кнопки и настройки в раздел **"Разное" (Others)** основного меню HeroWarsHelper:

- ⚙️ **Настройки кнопок**: Возможность изменения цвета кнопок расширения в разделе "Разное" для лучшей визуальной навигации.
- 🖥️ **Отключение графики (Game Graphics Switch)**: Специальный режим, который отключает игровую графику, оставляя активными только необходимые кнопки скрипта. Значительно снижает нагрузку на систему (CPU/GPU), что идеально подходит для многооконного режима или длительных задач (например, добычи титанита). Игра автоматически перезагружается для применения изменений.
- 📈 **Автоулучшение навыков (Skills Improvement)**: Автоматическая прокачка навыков выбранных героев. Первое улучшение происходит при загрузке игры, далее — по таймеру (каждые 25 минут). Скрипт уведомит, когда навыки достигнут максимального доступного уровня.
- 🗿 **Ресурсы для Титанов (Titan Resources)**: Удобный калькулятор, который показывает, сколько именно ресурсов необходимо для максимальной прокачки выбранных вами титанов.
- 🐾 **Прокачка питомцев (Pet Upgrade)**: Автоматизация развития питомца. Скрипт может самостоятельно экипировать камни, покупать их, улучшать и повышать уровень/ранг выбранного питомца по заданным параметрам.
- 🍀 **Удача и Колесо желаний**: Быстрый доступ к функциям автоматической траты монет удачи ("Lucky Road") и прокрутки "Колеса желаний" (Wheel of Wishes) в событии "Желание Судьбы".

## 📋 Требования

1. Браузер: Google Chrome, Firefox, Edge, Opera или любой другой современный браузер.
2. Менеджер пользовательских скриптов: [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) или [Greasemonkey](https://www.greasespot.net/).
3. **Обязательно:** Установленный и активный базовый скрипт **[HeroWarsHelper](https://github.com/)**.

## 🚀 Установка

1. Установите расширение для управления скриптами (например, **Tampermonkey**) в ваш браузер.
2. Убедитесь, что у вас установлен и работает скрипт **HeroWarsHelper**.
3. Перейдите по ссылке для установки:
   👉 **[Установить HWHHideButtonsExt](https://github.com/Green-oGo/HWHHideButtonsExt/raw/refs/heads/main/HWHHideButtonsExt.user.js)**
4. Нажмите кнопку **"Install" (Установить)** в открывшемся окне менеджера скриптов.

## 🎮 Использование

1. Откройте игру [Hero Wars](https://www.hero-wars.com/).
2. Дождитесь полной загрузки игры и инициализации скрипта HeroWarsHelper.
3. Откройте меню **HeroWarsHelper**.
4. Перейдите во вкладку **"Разное" (Others)**.
5. Нажмите на кнопку **⚙ (Настройки)**, чтобы изменить цвет кнопок, или выберите нужную функцию:
   - **Отключить графику** (для снижения нагрузки на ПК).
   - **Автоулучшение навыков** (выберите героев и активируйте таймер).
   - **Ресурсы для Титанов** (выберите титанов для расчета).
   - **Прокачка питомца** (настройте параметры и нажмите "Старт").
   - **Колесо желаний / Удача** (для быстрого доступа к событиям).
